# Restaurant Menu Display

A React app showcasing a restaurant menu with reusable components and list rendering, built with Vite.

## Features
- Reusable `MenuItem` component accepting props: `name`, `category`, `price`, `description`, and `isVegetarian`.
- Conditional rendering of a **Vegetarian** badge.
- Two categories rendered using `map()`: Main Courses and Desserts.
- Total items and restaurant info displayed.
- Basic responsive styling.

## Components
- `MenuItem` - `src/components/MenuItem.jsx`
- `App` - `src/App.jsx`
- `menu data` - `src/data/menuData.js`

## Run Locally
1. Clone the repository.
2. Run `npm install`
3. Run `npm run dev`
4. Open the URL shown by Vite (usually http://localhost:5173)
